# 🐍 Python Project

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)

This repository contains three different programs that cover basic to advanced concepts of Python programming. Each project is built around solving real-world problems and automation:

1. **Password Strength Checker**: Checks and evaluates how strong your password is.
2. **Calculator**: A command-line basic calculator that can perform five fundamental arithmetic operations.
3. **Student Grade Management System**: A complete system to store and manage student names, subject-wise marks, and their final grades.
4. **Password Guesser (Brute‑Force Demonstration)**: A script that demonstrates how a brute‑force attack works by systematically or randomly guessing passwords. **Purpose:** Educational — to show why weak passwords are dangerous, not to evaluate password strength.
5. **Automated Message Repeater (Clipboard + PyAutoGUI)**: A script that copies and pastes the message "Hello" and presses Enter every second. It runs infinitely. **Purpose**: To demonstrate Python's automation capabilities and clipboard manipulation.
