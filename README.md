# 🐍 Python Project

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)

This repository contains three different programs that cover basic to advanced concepts of Python programming. Each project is built around solving real-world problems and automation:

1. 👩‍💻 **Password Strength Checker**: Checks and evaluates how strong your password is.
2. 🧮 **Calculator**: A command-line basic calculator that can perform five fundamental arithmetic operations.
3. 🎓 **Student Grade Management System**: A complete system to store and manage student names, subject-wise marks, and their final grades.

## ✨ Project Features

### 📝 Password Strength Checker
Evaluates password strength based on the following conditions and provides feedback:
- **Length**: At least 8 characters.
- **Number**: Must contain at least one digit.
- **Uppercase & Lowercase**: Must contain both uppercase and lowercase letters.
- **Special Character**: Suggests using special characters to strengthen the password.

### 🧮 Calculator
What the user can do:
- **Addition (+)**
- **Subtraction (-)**
- **Multiplication (\*)**
- **Division (/)**
- **Average Calculation**

### 🎓 Student Grade Management System
A complete system that allows:
- ➕ Add a new student and their marks
- 👀 View the list of all stored students
- ✏️ Update a student’s information
- 🗑️ Delete a student’s information
- 🧑‍🎓 Automatically generate grades from `A+` to `F` based on marks
